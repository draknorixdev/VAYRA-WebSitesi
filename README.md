# VAYRA web sitesi

VAYRA uygulamasının tanıtım, gizlilik ve destek sitesi (statik, Türkçe). GitHub Pages ile yayınlanır:
https://draknorixdev.github.io/VAYRA-WebSitesi/

- `index.html` — ana sayfa
- `gizlilik/` — gizlilik politikası (Google Play mağaza girişi ve uygulama içi bağlantı bunu kullanır)
- `verilerimi-sil/`, `izinler/`, `destek/`, `kullanim-kosullari/`, `404.html`
- Yazı tipi: Plus Jakarta Sans (OFL), `assets/fonts/` içinde kendi sunucumuzdan.

Uygulamadaki bağlantılar `SiteLinks.kt` içindedir; bu klasör adlarını değiştirirsen orayı da güncelle.
